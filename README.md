# CCABM Official Website

This repository contains the source code scaffold for the Chinese Cultural Association of the Blind in Malaysia (CCABM) official website.

Generated by GitHub Copilot Chat Assistant.

Important notes

- This project uses React + TypeScript + Vite + Tailwind CSS and includes accessibility, bilingual (中文 / English), and theme (light/dark) support.
- Supabase placeholders are included for member portal demonstration. You must supply your Supabase project variables as environment variables for authentication features to work.

Quick start

1. Clone repository

   git clone https://github.com/ccabm2019/ccabm-official-website.git
   cd ccabm-official-website

2. Install dependencies

   npm install

3. Local development

   npm run dev

4. Build

   npm run build

Environment variables (for Supabase demo - optional)

- NEXT_PUBLIC_SUPABASE_URL
- NEXT_PUBLIC_SUPABASE_ANON_KEY
- SUPABASE_SERVICE_ROLE_KEY (server only, do NOT commit this key)

Deployment (Vercel)

- Connect your GitHub account to Vercel and import this repository.
- Add the Supabase environment variables in the Vercel project settings (if you use Supabase).
- Set build command: npm run build

Replace logo

Place your official logo in /public/ as logo.png or logo.svg. The site currently uses public/logo-placeholder.svg.

Accessibility & content

- All pages include keyboard navigation, skip-to-main, accessible labels and high-contrast themes.
- No real member data or real event photos are included. Replace placeholders with real assets as administrator.
